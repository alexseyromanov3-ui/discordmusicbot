# 🎵 Production-Ready Discord Music Bot

Высокопроизводительный, надежный и асинхронный музыкальный бот для Discord на базе `discord.py`, `yt-dlp` и `FFmpeg`.

---

## ✨ Возможности

- 🔍 **Умный поиск и прямые ссылки**: поддержка прямых ссылок YouTube и мгновенного поиска по названию песни / артисту.
- 📋 **Очередь воспроизведения**: независимая, потокобезопасная очередь для каждого сервера с автопереключением треков.
- 🎛️ **Интерактивные кнопки (Discord Buttons)**: управление плеером прямо под сообщением Now Playing (Пауза/Возобновить, Пропустить, Стоп, Повтор, Очередь).
- 🔁 **Режимы зацикливания (Loop Modes)**:
  - `OFF` — обычный режим;
  - `TRACK` — бесконечный повтор текущего трека;
  - `QUEUE` — циклическое воспроизведение всей очереди.
- 🔊 **Контроль громкости**: безопасная регулировка от 0% до 200%.
- ⏱️ **Автоотключение при простое (Idle Watchdog)**: освобождает ресурсы и покидает канал при отсутствии слушателей или музыки (настраиваемый таймаут).
- 🛡️ **Изоляция серверов**: каждый сервер обладает полностью независимым состоянием плеера, очереди и настроек.
- 🚀 **Асинхронность и безопасность**: все тяжелые операции с сетью и извлечением метаданных вынесены в фоновые потоки, не блокируя обработку событий Discord.

## 📋 Требования (Requirements)

- **Python**: 3.12 или выше (протестировано на Python 3.14)
- **FFmpeg**: установлен в системе (в PATH или указан в конфигурации)
- **Discord Bot Token**: с включенными необходимыми правами

## 🚀 Установка (Installation)

### 1. Клонирование репозитория или переход в папку
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd DiscordBot
```

### 2. Создание виртуального окружения
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Установка FFmpeg
- **Windows (через winget)**:
  ```bash
  winget install --id Gyan.FFmpeg.Essentials
  ```
- **Linux (Debian / Ubuntu)**:
  ```bash
  sudo apt update && sudo apt install ffmpeg
  ```
- **macOS (через Homebrew)**:
  ```bash
  brew install ffmpeg
  ```

## ⚙️ Настройка конфигурации (Configuration)

Скопируйте шаблон `.env.example` в `.env`:

```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

Откройте файл `.env` и настройте параметры:

```env
# Токен бота (получите в Discord Developer Portal)
DISCORD_TOKEN=ваш_секретный_токен_здесь

# Время до отключения бота при простое (в секундах, по умолчанию 300)
IDLE_TIMEOUT=300

# Громкость по умолчанию (от 0.0 до 2.0, где 0.5 = 50%, 1.0 = 100%)
DEFAULT_VOLUME=0.5

# Уровень логирования: DEBUG, INFO, WARNING, ERROR, CRITICAL
LOG_LEVEL=INFO

# Необязательный путь к ffmpeg (если ffmpeg не добавлен в системный PATH)
FFMPEG_PATH=
```

> ⚠️ **ВАЖНО**: Никогда не публикуйте и не сохраняйте ваш реальный `DISCORD_TOKEN` в публичные репозитории! Файл `.env` уже добавлен в `.gitignore`.

## 🤖 Настройка Discord Bot (Discord Bot Setup)

1. Перейдите в [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application** в правом верхнем углу и введите имя бота.
3. Перейдите во вкладку **Bot**:
   - Нажмите **Reset Token** и скопируйте полученный токен в переменную `DISCORD_TOKEN` в вашем `.env`.
   - В разделе **Privileged Gateway Intents** включите:
     - `Server Members Intent` (по необходимости);
     - `Message Content Intent` (не обязательно для slash-команд, но полезно).
4. Перейдите во вкладку **OAuth2** ➔ **URL Generator**:
   - В блоке **Scopes** отметьте:
     - `bot`
     - `applications.commands`
   - В блоке **Bot Permissions** отметьте:
     - `Send Messages`
     - `Embed Links`
     - `Attach Files`
     - `Connect`
     - `Speak`
     - `Use Voice Activity`
5. Скопируйте сгенерированную ссылку внизу и откройте её в браузере, чтобы пригласить бота на ваш сервер.

## 📜 Доступные команды (Commands)

| Слэш-команда | Параметры | Описание |
| :--- | :--- | :--- |
| `/play` | `query` *(текст или URL)* | Воспроизводит трек по ссылке YouTube или ищет первое совпадение по названию. Добавляет в очередь, если трек уже играет. |
| `/pause` | *нет* | Ставит текущий трек на паузу. |
| `/resume` | *нет* | Возобновляет воспроизведение после паузы. |
| `/skip` | *нет* | Пропускает текущий трек и переходит к следующему в очереди. |
| `/stop` | *нет* | Останавливает воспроизведение, очищает очередь и переводит бота в режим ожидания. |
| `/nowplaying` | *нет* | Отображает подробный Embed текущего трека с интерактивными кнопками управления. |
| `/queue` | `page` *(число, опционально)* | Показывает список треков в очереди с пагинацией. |
| `/volume` | `percent` *(от 0 до 200)* | Изменяет уровень громкости воспроизведения в процентах. |
| `/loop` | `mode` *(off / track / queue)* | Устанавливает режим зацикливания: выключен, текущий трек или вся очередь. |

## 🛠️ Устранение неполадок (Troubleshooting)

### 1. `FileNotFoundError: FFmpeg executable not found`
- **Причина**: FFmpeg не установлен или отсутствует в переменной PATH.
- **Решение**: Установите FFmpeg (например, `winget install Gyan.FFmpeg.Essentials` на Windows) или явно укажите полный путь к `ffmpeg.exe` в файле `.env` в параметре `FFMPEG_PATH`.

### 2. Бот не подключается к голосовому каналу
- **Причина**: У бота отсутствуют права `Connect` или `Speak` для конкретного канала/категории, либо канал переполнен.
- **Решение**: Проверьте роли и права бота в настройках канала на Discord-сервере.

### 3. Ошибка извлечения трека (`YouTube extraction error`)
- **Причина**: Устаревшая версия `yt-dlp` или видео ограничено по возрасту/региону.
- **Решение**: Обновите `yt-dlp` до актуальной версии:
  ```bash
  pip install --upgrade yt-dlp
  ```

### 4. Бот не отвечает на слэш-команды
- **Причина**: Слэш-команды не были синхронизированы при старте, либо бот добавлен без скоупа `applications.commands`.
- **Решение**: Перепригласите бота с отмеченными правами `applications.commands` и перезапустите `bot.py` для синхронизации дерева команд.

### 5. Ошибка 18+ ("Sign in to confirm your age" / возрастное ограничение)
- **Причина**: YouTube требует подтверждение возраста для некоторых треков и клипов.
- **Решение**:
  - Поместите файл `cookies.txt` (экспортированный из браузера через расширение, например Get cookies.txt LOCALLY) прямо в папку бота.
  - Либо укажите в `.env` браузер: `YOUTUBE_COOKIES_BROWSER=chrome` (или `edge`, `firefox`).
  - Бот автоматически подхватит авторизацию.
